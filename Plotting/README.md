# Plotting and Figure Generation

This directory contains scripts for generating figures and visualizations associated with the TrunCat and TrunKitten analyses.

The figures summarize nonsense-mediated mRNA decay (NMD) efficiency, premature termination codon (PTC) characteristics, transcript features, and model predictions.

## Overview

The plotting workflow uses processed datasets and model outputs generated by the upstream analysis pipelines.

```text
Processed and annotated datasets
              |
              v
Feature matrices and model predictions
              |
              v
       Plotting scripts
              |
              v
   Manuscript figures (PDF/PNG)
```

## Main Manuscript Figures

The scripts in this directory are used to visualize results from the TrunCat analyses, including:

- NMD efficiency across different PTC positions and transcript contexts.
- Canonical and non-canonical NMD-related features.
- Relationships between transcript features and NMD efficiency.
- Machine-learning model performance and feature importance.
- Sequence-context and RNA-binding protein motif analyses.

Refer to the individual plotting scripts for the corresponding figure panels and required input datasets.

## Requirements

Plotting scripts are primarily written in R, with selected analyses implemented in Python notebooks.

Common R packages include:

- `ggplot2`
- `dplyr`
- `ggpubr`
- `patchwork`
- `ggbeeswarm`
- `scales`

Additional packages may be required for individual figures.

## Reproducibility

Figure-generation scripts should be run after completing the corresponding data processing, feature extraction, and model prediction steps.

The plotting scripts do not retrain the prediction models unless explicitly indicated.

For the upstream workflows, see:

- [Dataset extraction](../Dataset_extraction/)
- [Annotation](../Annotation/)
- [Feature generation](../Features/)
- [Model development](../Model/)
- [External validation](../External_validation/)

The manuscript figure numbering and panel assignments should be checked against the final submitted version.
